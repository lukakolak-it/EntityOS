# Post-v0.1 Roadmap

## Priority 1: Better Real-World Quality

- collect anonymized review feedback from first external users
- add each recurring bad result as an eval case
- improve source quality thresholds and use-case defaults
- keep default CI secret-free

## Priority 2: Use Case Portability

- improve import/export ergonomics for use cases
- add more example packs for project, vendor and local organization research
- document how custom criteria map to rules and LLM prompts

## Priority 3: UI Review Speed

- faster triage for large queues
- clearer evidence-to-draft linking
- optional browser screenshot regression suite

## Not Planned For Early v0.x

- hosted SaaS
- remote user accounts
- automated outreach
- telemetry collection
- scraping behind logins or paywalls
