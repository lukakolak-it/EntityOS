# v0.1.0-local-osint Release Notes

Status: release candidate.

Tag target: `v0.1.0-local-osint`

## Scope

This release is a local-first OSINT and research workflow tool. It supports
local discovery runs, source quality classification, use-case based rating,
draft generation and a local review UI.

## What Works

- Start a fake demo without provider secrets.
- Configure Brave, Ollama and optional OpenAI in `.env` or `/#secrets`.
- Run Company OSINT and Open-Source project style searches.
- Review targets, filter queues, make bulk decisions and undo review status.
- Export local diagnostics and local run data without secrets.
- Run deterministic tests and eval gates locally or in GitHub Actions.

## Quality Gates

The release candidate is expected to pass:

```powershell
$env:PYTHONPATH='src'
py -m compileall src
py -m unittest discover -s tests
py -m target_radar.cli evaluate
py -m target_radar.cli privacy-check --root .
node --check src\target_radar\web\static\app.js
git diff --check
```

## Known Risks

- Real search results can be noisy and require review.
- LLM scoring is only as good as the local/provider model and evidence.
- No remote auth, no multi-user permissions, no public-server hardening.
- Screenshots are documented descriptively; browser screenshot CI is not part
  of this release candidate.

## Tagging Checklist

1. Run all quality gates.
2. Run the demo walkthrough from a clean checkout or archive.
3. Confirm `privacy-check` is green.
4. Confirm `CHANGELOG.md` and this release note are current.
