# Code of Conduct

This project is intended to be a practical, respectful engineering space.

## Expected Behavior

- Be direct, specific, and respectful.
- Discuss technical tradeoffs with evidence.
- Assume good intent, but respond to concrete harm.
- Keep issue reports reproducible and redacted.
- Respect privacy when sharing OSINT examples or eval cases.

## Unacceptable Behavior

- Harassment, threats, hate speech, or personal attacks.
- Publishing private data, secrets, credentials, or doxxing material.
- Repeatedly derailing technical discussions.
- Using the project to automate spam, harassment, or unauthorized access.

## Enforcement

Maintainers may edit, hide, or close issues and pull requests that violate this
policy. Serious or repeated violations can lead to a ban from project spaces.

Security-sensitive or privacy-sensitive reports should follow `SECURITY.md`
instead of being posted publicly.
